# ReservaFácil

## Presentación

**ReservaFácil** es una aplicación diseñada para facilitar la gestión de reservas en restaurantes y otros establecimientos que trabajan con citas o reservas.

El objetivo del proyecto es ofrecer una solución **sencilla, rápida y accesible** tanto para los clientes como para el personal del establecimiento.

![Restaurante](image/salaMesas.avif)

> **Objetivo:** simplificar el proceso de reserva y ayudar al establecimiento a organizar mejor su actividad.

## ¿Cómo funciona?

El cliente podrá utilizar la aplicación para consultar la disponibilidad y realizar una reserva indicando la fecha, la hora y el número de personas.

Por otra parte, el establecimiento contará con herramientas para consultar y gestionar las reservas realizadas.

Entre las principales características del proyecto se encuentran:

- Consulta de disponibilidad.
- Creación de reservas.
- Gestión de clientes.
- Consulta y modificación de reservas.
- Gestión de mesas y horarios.
- Comunicación entre las diferentes partes del sistema.

## Pensado para las personas

ReservaFácil busca que realizar una reserva sea una tarea **rápida y cómoda**, evitando llamadas telefónicas innecesarias y reduciendo los errores derivados de una gestión manual.
