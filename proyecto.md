# El proyecto

## ¿Qué problema queremos solucionar?

La gestión de reservas puede resultar complicada cuando un establecimiento utiliza diferentes medios para organizar las solicitudes de sus clientes.

Las llamadas telefónicas, mensajes y anotaciones manuales pueden provocar **errores, reservas duplicadas o pérdida de información**.

ReservaFácil nace con la finalidad de centralizar este proceso en una única plataforma.

## Nuestra propuesta

La aplicación permitirá gestionar las reservas de una manera organizada y sencilla.

El cliente podrá:

1. Acceder a la aplicación.
2. Consultar la disponibilidad.
3. Seleccionar una fecha y una hora.
4. Indicar el número de personas.
5. Confirmar la reserva.
6. Consultar sus reservas posteriores.

El establecimiento podrá consultar las reservas recibidas y organizar la disponibilidad del negocio.

## Público objetivo

ReservaFácil está pensado principalmente para:

- Restaurantes.
- Cafeterías.
- Pequeños establecimientos de hostelería.
- Negocios que trabajen con reservas.
- Clientes que quieran realizar reservas de forma rápida.

## Beneficios

El proyecto pretende aportar diferentes ventajas:

- **Ahorro de tiempo** en la gestión de reservas.
- **Mayor organización** de la información.
- Reducción de posibles errores.
- Mayor comodidad para los clientes.
- Acceso a la información de las reservas desde una plataforma centralizada.

## Una solución escalable

El proyecto está planteado para poder incorporar nuevas funcionalidades en el futuro.

> **Nota:** las funcionalidades descritas en esta documentación representan la propuesta inicial del proyecto y podrán evolucionar durante su desarrollo.
